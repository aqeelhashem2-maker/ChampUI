# Code of conduct

Treat contributors with respect. Welcome questions, give feedback on the work, and respect privacy. Harassment, discriminatory behavior, threats and publishing another person’s private information without permission are unacceptable.

Report concerns privately to a maintainer through an established project channel when available. If there is no private channel, ask a maintainer for one without sharing the details publicly. Maintainers may remove harmful content or restrict participation and will handle reports with discretion.
