## ما كشفه الاختبار

في إحدى المحاولات انتهت مهلة انتظار مسار الأسعار عند النقر على رابط التنقل. كان الاختبار ينقر قبل التأكد من جاهزية دائرة Blazor، ثم يعيد تحميل الصفحة مباشرة بعد الانتقال. عُدّل الاختبار لينتظر تفعيل عنصر تفاعلي، ويتحقق من المسار ويختبر الصفحة التي فتحها الرابط. بقيت تأكيدات التفاعل والبيانات مفعّلة. لم يتطلب التحقق تغيير أي مكوّن إنتاجي.

## نطاق الأدلة

- جرى التقييم العملي لوكلاء البرمجة وإعادة تشغيل المخرجات المحفوظة. درجة النجاح تقيس هذه الطلبات المحددة، ولا تتنبأ بدقة كل نموذج في كل جلسة.
- استند تثبيت Claude Code واستدعاء ‎/champui إلى وثائق المنتج. لم يتوفر عميل Claude Code محلي لإجراء تجربة تشغيل مستقلة. يصف دليل ChatGPT استخدام ملفات وتعليمات المشروع يدويًا. التوزيع هنا عبر مستودع GitHub.
- غطّى Chromium لوحة المفاتيح والتركيز والأسماء الميسّرة والتخطيط. لم يُجر اختبار يدوي لقارئ شاشة على الصفحات الجديدة. ويتطلب اعتماد قاعدة بيانات علائقية أو خدمة خارجية اختبار SQL والمصادقة والتزامن على بيئة التطبيق.
- تقتصر المهارة على مكوّنات ChampUI المنشورة. تظل عمليات الدفع والتسوية وجدولة التوافر المتقدمة ضمن نطاق خدمات التطبيق.

يمكن إعادة الفحص باتباع [خطوات التثبيت والتقييم](README.md#evaluate). يشغّل [مسار GitHub Actions المخصص](../../.github/workflows/champui-skill.yml) أمثلة التوثيق ومخرجات المهارة على Ubuntu، إلى جانب مسار Core المعتاد.
