# UiSkeleton

Set the placeholder dimensions to match the content that will replace it.

Namespace `ChampUI.Components.Display`. Generic parameters: none. [Razor source](../../../src/ChampUI/Components/Display/UiSkeleton.razor).

| Parameter | C# type | Supply | Initial value |
| --- | --- | --- | --- |
| `Width` | `string` | optional | `"100%"` |
| `Height` | `string` | optional | `"14px"` |
| `Circle` | `bool` | optional | `false` |
| `Class` | `string?` | optional | `null` |
| `Style` | `string?` | optional | `null` |

Callbacks: none. Child slots: none.

## Example

```razor
<UiSkeleton Width="8rem" Height="1rem" />
```
