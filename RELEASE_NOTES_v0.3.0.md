# ChampUI v0.3.0 public source candidate

**Developed by Sadeem Systems.** This local candidate includes a neutral ChampUI Showcase, the MIT-licensed library for .NET 10, and the public verification fixtures. It preserves the public component APIs and behavior of the locally verified library.

The showcase demonstrates forms, themed layout, charts and the DataGrid. Local grids support inline editing, and the paged and virtual providers demonstrate query-aware exports. Virtual-provider Select All remains limited to loaded row identities. Browser verification targets Chromium. Optional Firefox and WebKit checks do not establish broader coverage.

This public preparation has no published package and no public release tag.
