# ChampUI 0.3.2

UiDialog moves focus inside when opened, keeps Tab and Shift+Tab in the active modal, and isolates background content while the dialog is open. Closing restores focus to the opener when usable and uses a workflow fallback when the opener is removed or disabled. Escape, close-button, and backdrop dismissal continue to use the existing callbacks. An optional plain-text Description can be announced with the dialog title.
